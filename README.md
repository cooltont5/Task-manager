Task Manager

About

This program notes down tasks and allows them to be marked as complete. It helps keep track of multiple tasks that you may struggle to remember to do.

Features

- Add tasks
- Remove tasks
- View tasks
- Mark tasks as complete
- Save tasks so they remain after the program is restarted
- Handle invalid user input

How It Works

The program uses a Python list and a text file to store information. This allows the program to load previously saved tasks when it is restarted and continue from where it last stopped. Using the list, the program is able to locate specific tasks that the user wants to remove or mark as complete. Changes made to the list are then saved to the file.
